# Функциональные доработки KSP App

Источник требований: `outputs/functional-roadmap.md`, план реализации: `plan.md`. Отмечать выполненными только после фактической реализации поведения.

## Авторский цикл КСП

- [x] **Надёжное автосохранение:** показываются разные статусы локального сохранения, синхронизации, серверного сохранения, offline, retry и ошибки; время последнего успешного серверного сохранения не подменяется локальным; локальный черновик не затирает более новую серверную версию молча; конфликт даёт выбрать серверную или локальную копию и безопасно сравнить их; черновики разделены по планам; сбой localStorage/сети/валидации виден и не объявляется успешным сохранением.
- [ ] **Проверка готовности КСП:** проверки выявляют цели без заданий, задания без существующих целей, несогласованность критериев и заданий, незаполненные/невыполнимые этапы и проблему хронометража/баллов по выбранному профилю урока; каждый результат объяснён и ведёт к исправляемому полю; предупреждения не блокируют не относящееся к ним действие; эвристики не заявляют официальное нормативное соответствие.
- [x] **Сравнение/частичное восстановление версии:** сравнение показывает добавленные, изменённые и удалённые поля/секции; выборочная замена имеет предпросмотр; невключённые секции не меняются; восстановление создаёт новую версию, сохраняет текущую видимость публикации и при устаревшей версии показывает конфликт, не затирая новые изменения.
- [x] **Библиотека блоков КСП:** учитель может найти и предварительно просмотреть свой этап/задание/критерий и вставить независимую копию; изменения копии не меняют источник; фиксируется происхождение копирования; несовпадение класса/языка/цели явно предупреждается; чужие приватные материалы не раскрываются.

## AI-помощник

- [x] **Карточка контекста AI/RAG:** показываются фактически переданные предмет/класс/тема/язык/цели и реальные использованные источники; при неудаче RAG явно написано, что ответ был без учебника; сведения доступны только владельцу и уполномоченным лицам; chain-of-thought, секреты и лишние персональные данные не сохраняются/не раскрываются.
- [x] **Варианты отдельного задания:** AI предлагает 2–3 альтернативы по запросу учителя; каждый вариант проходит схему задания; есть предпросмотр и явные принять/отклонить; до принятия исходник сохраняется; принятие не меняет другие секции, а изменение целей/баллов требует явного решения.
- [x] **Метки проверки AI-материала:** наличие источника и ручная проверка учителем представлены раздельно; автоматическая проверка не ставит статус «проверено учителем»; изменения сбрасывают отметку только у изменённого блока; служебные отметки не раскрываются ученику.
- [ ] **История контекста AI:** сохраняются минимальные метаданные запроса, параметров, модели/версии схемы и идентификаторов источников, без ключей, chain-of-thought и ненужного сырого содержимого; повтор генерации открывается только как preview и не перезаписывает план до принятия; события доступны только уполномоченным и удаляются по установленной политике.

## Задания и обратная связь ученику

- [x] **Мастер «КСП → материал → выдача»:** до выдачи учитель выбирает задания, задаёт срок и режим, видит страницу ученика и явно подтверждает публикацию; выдача сохраняет snapshot и не меняется вслед за исходным КСП; правильные ответы не попадают в публичный ответ; доступна ссылка/QR и явные статусы open/closed/expired.
- [x] **Агрегированная аналитика по целям:** отчёт показывает размер выборки и знаменатель, точность/пропуски/попытки по заданию и учебной цели; отсутствие ответов не маскируется нулём; малые группы (меньше 5 участников) не раскрываются сравнительными процентами; индивидуальные строки доступны только авторизованному учителю; описательные подсказки не являются диагнозами/автооценками.
- [x] **Обратная связь и повторная практика:** режим показа разбора задаёт учитель; персональный результат не раскрывается группе; повторный набор учитель проверяет/редактирует; повторная выдача получает новый код, срок и snapshot, сохраняет связь с исходной, а исходная выдача/попытки не меняются; ясно различаются лучший и последний результат.

## Школьная координация

- [ ] **Матрица полномочий школы:** единые серверные permission checks применяются к просмотру, изменению, оцениванию, комментариям, ролям и экспорту; UI и API согласованы, но API защищён независимо; член другой школы не получает данные; нельзя повышать собственную роль; существенные изменения доступа записываются без чувствительного содержимого.
- [ ] **Согласование плана:** состояния draft/submitted/in_review/changes_requested/resubmitted/approved относятся к фиксированному snapshot; комментарии привязаны к секции; автор и проверяющий видят корректную очередь/статус; решения содержит автора, время и версию; автор не утверждает собственный план; изменение после отправки формирует новую версию и не меняет одобренный snapshot.
- [ ] **Прозрачный безопасный экспорт:** школьный отчёт содержит дату, фильтры, период/часовой пояс, знаменатели, неполноту данных и происхождение ручных/вычисленных/импортированных полей; выгружаются только разрешённые строки/колонки; чувствительные идентификаторы по умолчанию исключены; CSV/Excel защищён от formula injection; заголовки RU/KZ локализованы.

## Полировка

- [ ] **Казахская локализация критических сценариев:** формы КСП, AI, quality/history, школьные формы, выдачи/результаты, состояния ошибки/загрузки/пустых данных, aria-label и экспорт доступны на KZ; дата/числа/множественное число форматируются локально; ключи проверяются автоматически; сырой translation key никогда не показывается.
- [ ] **Мобильные ключевые сценарии:** на 320/360/390 px доступны просмотр КСП, QR/ссылка выдачи, управление live-квизом и результаты; основные кнопки не теряются; формы не перекрываются клавиатурой; широкие таблицы имеют пригодное мобильное представление. Частично: таблица результатов получила карточное mobile-представление; предстоит проверить выдачу/QR, страницу КСП и live-квиз на целевых ширинах.
- [ ] **Доступность:** сценарии доступны с клавиатуры; поля имеют accessible names и связанное описание ошибок; порядок/видимость фокуса предсказуемы, modal возвращает фокус; важные статусы объявляются без избыточного чтения; цвет не единственный носитель смысла; графика имеет корректный alt; соблюдаются контраст и reduced-motion.
- [ ] **Центр уведомлений:** in-app уведомления по комментариям/согласованиям/результатам/операциям отображаются только адресату с актуальным доступом; доставка идемпотентна; read/unread устойчивы; сводки не содержат ответы и лишние персональные данные; категории/частота и внешние каналы — с добровольным выбором.

## Сквозная интеграция

- [ ] **Совместимость, приватность и учительский контроль:** существующие планы, выдачи, версии и пользователи продолжают работать; новые записи имеют обратную совместимость; сервер проверяет владельца и роль при каждом действии; AI не публикует, не выставляет итоговые оценки и не назначает диагнозы автоматически; журналы не содержат секретов и полного приватного содержимого; изменения не тестируются разрушительными записями в production.
