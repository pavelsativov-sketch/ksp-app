# План переработки (КСП → План → Материалы, ОС-агент BilimClass)

Решение: ничего не удаляем, берём готовое и доводим. Связь с Vercel, Mongo и ключами не трогаем.
Цели обучения берутся только из ГОСО (`data/goso_official.json`, 5 461 цель, 24 предмета).

## Шаг 1. Ядро: цели ГОСО → КСП → План
- Цели КСП подбираются из ГОСО автоматически по предмету, классу и теме, если учитель их не выбрал.
  В КСП попадают только реальные коды и тексты из ГОСО, придумывать цели ИИ запрещено.
- Один сервис собирает КСП для сайта и для агента (сейчас агент оставлял `learningObjectives` пустым).
- Страница плана становится центром: оттуда запускаются все материалы.

## Шаг 2. Материалы из плана
Уже есть: рабочие листы, карточки, кроссворд (`src/lib/handouts`), задания и живой квиз (`src/lib/ksp`).
Доделать:
1. Интерактив из 5–10 выборов (ветвящийся сценарий урока).
2. Рабочие листы по образцам учителя.
3. «Слова педагога»: речь учителя по этапам урока.
4. Кроссворд с автопроверкой, привязанный к терминам плана.
Все материалы строятся от одного плана и целей ГОСО.

## Шаг 3. Агент BilimClass
Основа работает (автовход, чтение журнала). Доделать: всегда возвращать результат
(частичный отчёт вместо зависания), больше проверенных сценариев, подсказки по разделам.
