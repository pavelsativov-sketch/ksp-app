# Комплект урока: КСП и материалы, связанные между собой

Статус: черновик на согласование с владельцем, 2026-11-17.

## Зачем

Сейчас КСП и материалы живут отдельно:

- КСП создаётся без вопросов о том, как пройдёт урок;
- материалы (лист, ООП, групповые карточки, кроссворд, карточки, презентация) хранятся только в браузере учителя (`localStorage`), и КСП о них не знает;
- в колонке «Ресурсы» и «Оценивание» нет ссылок на эти материалы и их баллы;
- с этапом урока связаны только интерактивные задания (`stage.tasks`).

Цель: урок — это один комплект. Что учитель выбрал, то есть и в КСП, и в материалах, и в презентации. Если что-то меняется в одном месте, остальное это видит.

## Решения владельца (2026-11-17)

- Вопросы перед КСП — красивое 3D-меню, вопрос про учеников с ООП обязателен.
- Выбранные материалы создаются сразу в фоне: КСП открывается без ожидания, материалы появляются на своих этапах по мере готовности.
- Этапов урока остаётся три: начало, середина, конец.

## 1. Поток учителя

1. **Тема.** Класс, предмет, тема — как сейчас (быстрая карточка на главной или форма).
2. **3D-меню «Что будет на уроке».** Один экран, без пошагового мастера. Плитки с объёмными иконками и анимацией выбора, разумные значения по умолчанию, «Создать урок» доступна сразу.
   - Формы работы: индивидуальная (включена), парная, групповая (+ сколько групп: 2–4).
   - Ученики с ООП: нет / есть. Если есть — короткое уточнение (зрение, слух, ЗПР, речь, другое, свободное поле). Это включает лист ООП и строку про ООП в каждом этапе КСП.
   - Материалы: рабочий лист (вкл.), лист ООП (вкл. при ООП), карточки групповой или парной работы (вкл. при выбранной форме), интерактив (тип: квиз, пары, пропуски, порядок), кроссворд, карточки в тетрадь, презентация (вкл.).
   - Ценность урока: список «Адал азамат» или «подобрать ИИ».
   - Язык и длительность (45 или 40 минут).
3. **Создание.** КСП генерируется с учётом ответов и открывается. На этапах видны «места» под материалы со статусом: готовится → готово (или «не получилось, повторить»).

## 2. Данные

Новое в `KspContent`:

```ts
kit?: {
  workForms: Array<"individual" | "pair" | "group">;
  groups?: number;                       // 2–4, если есть групповая/парная
  oop?: { present: boolean; notes?: string };
  value?: string;                         // ценность урока
  minutes: 40 | 45;
  slots: MaterialSlot[];
};

interface MaterialSlot {
  id: string;
  kind: "worksheet" | "oop_sheet" | "group_cards" | "pair_cards" | "interactive" | "crossword" | "flashcards" | "deck";
  stage: "beginning" | "middle" | "end";
  status: "planned" | "generating" | "ready" | "failed";
  materialId?: string;                    // запись в plan_materials
  title: string;                          // как материал назван в КСП
  error?: string;
}
```

В каждом этапе (`LessonStage`) — структурный список действий рядом с текстом:

```ts
activities?: Array<{ form: "individual" | "pair" | "group" | "frontal"; title: string; minutes?: number; slotId?: string }>;
```

Новая коллекция `plan_materials`: `{ _id, plan_id, owner_id, kind, stage, payload, created_at, updated_at }`. Здесь лежат лист, лист ООП, карточки, презентация и т. д. `localStorage` остаётся только кешем.

## 3. Как КСП узнаёт о материалах

- Промпт КСП получает комплект: какие формы на каком этапе, сколько групп, есть ли ООП, ценность, список слотов.
- Модель возвращает этапы с `activities`. Например, середина: «Групповая работа: карточки (3 группы)» → «Индивидуальная работа: рабочий лист, задания 1–5, 10 баллов». В тексте действий педагога и учеников эти материалы названы явно.
- Колонка «Ресурсы» собирается из слотов этапа автоматически.
- В каждом этапе есть строка про ученика с ООП, если `oop.present`.

## 4. Как материалы узнают о КСП

- **Рабочий лист** строится по индивидуальному действию своего этапа и критериям урока. Его задания и баллы записываются обратно в КСП (колонка «Оценивание»: «Задание 1. … — 2 балла»).
- **Лист ООП** — из того же листа (`toOopSheet`), учитывает `oop.notes`.
- **Групповые и парные карточки** — `groups` штук, ситуации по теме этапа, ценность урока.
- **Интерактив** создаётся в слоте или позже: учитель выбирает этап, задание попадает в `stage.tasks` (уже так работает) и в `activities`.
- **Презентация** собирается по КСП и комплекту: слайд «Групповая работа» перечисляет задания групп из карточек, «Оценивание» — дескрипторы и баллы листа.

## 5. Согласованность

На странице урока — панель «Комплект»:

- в КСП есть действие, а материала нет → «Создать карточки для групповой работы» прямо на этапе;
- материал есть, но в КСП не используется → «Подключить к этапу…» (выбор этапа, текст этапа дописывается);
- баллы листа и колонка «Оценивание» расходятся → «Обновить оценивание»;
- материал удалён → действие помечается: «создать заново» или «убрать из КСП».

Материал, созданный позже из плитки на странице урока, всегда спрашивает «к какому этапу подключить?» и становится слотом комплекта.

## 6. Фоновая генерация

- После сохранения КСП браузер учителя запускает генерацию всех слотов параллельно — отдельными запросами к уже существующим маршрутам (лист, карточки, презентация). Сервер сохраняет результат в `plan_materials` и обновляет статус слота.
- Учитель может уйти со страницы: готовые материалы сохранены на сервере, при возвращении статусы подтянутся.
- Ограничение: если учитель закроет вкладку до окончания, недоделанные слоты останутся «запланированными» с кнопкой «создать». Очередь задач на сервере не нужна.

## 7. Этапы реализации

1. Данные и сохранение материалов на сервере (`kit`, `plan_materials`, перенос с `localStorage`).
2. 3D-меню вопросов перед КСП.
3. Генерация КСП с комплектом (`activities`, ресурсы, ООП, ценность).
4. Фоновая генерация слотов и статусы на этапах.
5. Обратная связь: баллы листа → «Оценивание», «подключить к этапу», панель согласованности.
6. Презентация и Word-экспорт КСП по комплекту.

Каждый этап — отдельная выкладка с проверкой на живом уроке.
