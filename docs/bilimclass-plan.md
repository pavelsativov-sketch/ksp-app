# Интеграция с BilimClass.kz — план (не реализовано)

## Текущий статус

Интеграции **нет**. Раньше существовал адаптер-заглушка
`src/lib/bilimclass/client.ts`, который ни разу не импортировался, а при
настроенных переменных окружения возвращал `ok: false` — то есть тихо
проваливался. Заглушка удалена, чтобы мёртвый код не выглядел как рабочая
функция. Этот файл хранит план, чтобы он не потерялся.

Осознанное решение: интеграция отложена, потому что требует внешних
ресурсов, которых у проекта нет.

## Что нужно от BilimClass

1. **Документация API** — эндпоинты, схемы, версионирование.
2. **Сервисный токен** уровня организации (не персональный токен учителя).
3. **Ответ на ключевой вопрос:** нужно ли выгружать КСП в BilimClass, или
   достаточно ссылки на готовый материал у нас. От этого зависит вся схема.

Переменные окружения, которые понадобятся:

```
BILIMCLASS_API_URL      — например, https://api.bilimclass.kz
BILIMCLASS_API_TOKEN    — сервисный токен организации
```

## План реализации по шагам

**Шаг 1. Клиент и схемы.** `src/lib/bilimclass/client.ts` — реальный HTTP-клиент
на `fetch` с таймаутом и повтором. Zod-схемы ответов. Клиент скрывает за собой
`LessonPlanRow` и отдаёт наружу `BilimClassPushResult` (уже был такой тип).

**Шаг 2. Маппинг КСП.** Написать `toBilimClassPlan(plan): BilimClassLesson`,
которая переводит наш `content` в формат LMS. Скорее всего, потребуется
таблица соответствий секций: у нас 13 секций шаблона РК, у BilimClass свой набор.
Явно решить, что теряется при несовпадении.

**Шаг 3. Выгрузка интерактивов.** Наши задания — это ссылка на страницу
(`/plans/<id>` с интерактивом). Варианты: выгружать полный JSON задания либо
отдавать ссылку. Первый надёжнее, второй проще.

**Шаг 4. Кнопка и статус.** Кнопка «Отправить в BilimClass» на странице плана
у владельца. Показывать результат: `externalId`, ссылка на материал в LMS.
Хранить `external_id` в `lesson_plans`, чтобы повторная отправка обновляла
существующий материал, а не плодила дубли.

**Шаг 5. Ошибки и синхронизация.** Различать: неверный токен, превышение
квоты, материал не найден. Не ретраить 4xx. При рассинхронизации — кнопка
«Синхронизировать заново».

**Шаг 6. Тесты.** Мок HTTP-клиента: успешная отправка, 401 без тика,
идемпотентность повторной отправки, маппинг секций наsnapshot-тесте.

## Оценка

При наличии документации и токена — **M** (2–3 дня). Без документации
интеграция не начинается: угадывать контракт опасно, так как ошибка приведёт
к тихой порче данных у пользователей LMS.

## Что можно сделать сейчас без BilimClass

Экспорт в Word/HTML/ZIP уже покрывает потребность «передать план коллегам или
в методкабинет». Пока эта задача не закрыта, интеграция с LMS не является
блокером для продукта.
